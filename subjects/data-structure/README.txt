DSA 101 RESPONSIVE COURSE WEBSITE
=================================

Built using only:
- HTML
- CSS
- JavaScript

No Bootstrap, Tailwind, React, or other frameworks.

FILES
-----
index.html
css/style.css
js/script.js

RESPONSIVE DESIGN
-----------------
DESKTOP
- Top navigation is visible.
- W3Schools-style subject navigation is visible in the left pane.
- Main content is displayed on the right.

TABLET
- Top navigation remains visible.
- Left subject navigation remains visible.
- Main content adapts to the smaller screen.
- No dark mode.
- No collapse-menu button for the left pane.

MOBILE
- The desktop top navigation and left subject navigation are merged.
- A hamburger button opens one combined navigation panel.
- The combined menu displays:
    1. Overview
    2. Prelims
    3. Midterms
    4. Finals
    5. Grading System
    6. Subject Content
       - Prelims topics
       - Midterms topics
       - Finals topics
       - Grading System
       - Resources
- No dark mode.
- No left-pane collapse menu.

SCROLL HIGHLIGHTING
-------------------
JavaScript highlights the current:
- Top navigation section
- Left subject navigation topic
- Topic tab

As the student scrolls through a lesson, the corresponding navigation
item is highlighted.

BACK TO TOP
-----------
A floating Back to Top button appears after the user scrolls down.

CUSTOMIZATION
-------------
Edit index.html to change:
- Course name
- Course code
- Instructor
- Description
- Topics
- Lesson content
- Footer details

Edit css/style.css to change:
- Colors
- Sizes
- Spacing
- Responsive breakpoints

Edit js/script.js to change:
- Mobile menu behavior
- Scroll highlighting
- Back-to-top behavior
