1. Introduction

1.1 What is DSA?

Data Structures and Algorithms (DSA) is a way of organizing and processing data efficiently in a computer. In understanding DSA, it is essential to have a basic understanding of programming.


Example:

When you search for a contact in your phone, the data is stored in some structure, such as a list or tree, and the search is done using an algorithm.

Data vs Information
Data refers to raw facts and figures.
Information is processed and organized data that has meaning and can be used to make decisions.

Example:

Data: 25, 30, 28, 35, 32
 These are just numbers without context.

Information: "The temperatures for the past five days were 25°C, 30°C, 28°C, 35°C, and 32°C. The hottest day was 35°C."
 The data has been organized and given meaning, making it useful.

Another Example:

Data: Mars, Chris, Kyle, John, Rico
 These are just random names and we don't know who they are.

Information: "The starting lineup of Team Icon for the Basketball Championship are Kyle, John, Chris, Mars and Rico"
 In the information, the data was processed and given meaning.

1.2 Data Structures

A data structure is a way of organizing and storing data so that we can use it efficiently in a computer.


Classification of Data Structure

Data structures are commonly classified into two major categories: Primitive and Non-Primitive

Primitive Data Structures

These are the basic data types provided by a programming language.

  • Integer
  • Float/Double
  • Character
  • Boolean
  • String/Varchar
Non-Primitive Data Structures

These are more complex data organizations created by combining primitive data types (like integers, floats, and characters) to store, manage, and manipulate collections of data efficiently.

Unlike primitive types that store a single value directly in stack memory, non-primitive structures usually store references or memory addresses to objects allocated dynamically in the heap memory.


Non-Primitive Data Structures are divided into two categories, Linear and Non-Linear data structures.

A. Linear Data Structures
In a linear data structure, elements are arranged sequentially, one after another.
  • Array
  • Linked List
  • Stack
  • Queue
B. Non-Linear Data Structures
In a Non-Linear Data Structures, elements are not arranged sequentially. They can have hierarchical or network relationships.
  • Tree
  • Graph

1.3 Algorithms

An algorithm is a step by step process, procedure or instruction to solve a problem or to perform or accomplish a specific task.

Characteristics of an Algorithm
  • Input: one or more inputs may be provided.
  • Output: one or more outputs are produced.
  • Definiteness: each step must be clear and unambiguous.
  • Finiteness: the algorithm eventually terminates.
  • Effectiveness: each step is practical and executable.

1.4 Algorithm Complexity

Algorithm complexity describes how an algorithm's resource requirements change as the input size increases.

1.5 Time & Space Complexity

Time complexity measures execution growth, while space complexity measures the additional memory required. Big O notation is commonly used to describe algorithm efficiency.

2. Arrays

2.1 What is an Array?

An array stores multiple values in an ordered collection. Each element can be accessed using its index. 

let numbers = [10, 20, 30, 40]; console.log(numbers[0]); // 10

2.2 Array Operations

Common array operations include traversal, searching, insertion, and deletion.

3. Searching

3.1 Linear Search

Linear search checks elements one at a time until the requested value is found or the list ends.

3.2 Binary Search

Binary search works on sorted data and repeatedly divides the search interval in half.

4. Sorting

4.1 Common Sorting Algorithms

Sorting arranges data into a particular order. Common algorithms include Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort. 

// Simple Bubble Sort
                    for (let i = 0; i < numbers.length; i++) {
                        for (let j = 0; j < numbers.length - i - 1; j++) {
                            if (numbers[j] > numbers[j + 1]) {
                                let temp = numbers[j];
                                numbers[j] = numbers[j + 1];
                                numbers[j + 1] = temp;
                            }
                        }
                    }
